# Programming Lessons

Навчальний сайт із 19 довідниками. Початкові HTML-файли в корені залишаються джерелом навчального контенту та оформлення. Готовий сайт збирається в **`dist/`**; саме цю папку потрібно відкривати або публікувати.

## Запуск

Потрібен Node.js 22 або новіший.

```sh
npm ci
npm run build
npm test
npm run preview
```

Локальний перегляд: <http://127.0.0.1:4173>. Можна також відкрити `dist/index.html` як звичайний файл. Вбудовані переклади, пошук і практика не потребують зовнішнього сервера. Збереження через `file://` залежить від дозволів браузера; для перевірки прогресу краще використовувати локальний сервер.

## Що змінено

- Готовий HTML із текстом уроків, таблицями й прикладами, доступний без JavaScript.
- 100 сторінок: 20 сторінок українською в корені, а також англійські, російські, індонезійські й японські версії в `en/`, `ru/`, `id/`, `ja/`.
- Унікальні заголовки й описи, canonical, взаємні hreflang, Open Graph, Twitter Card, WebSite / CollectionPage / LearningResource / BreadcrumbList.
- `robots.txt`, карта сайту на 100 адрес, 404 і перенаправлення старих адрес із `?lang=`.
- Пошук по довідниках, пошук перекладених тем усередині сторінки, прямі посилання на теми, навчальні маршрути й офіційна документація.
- Прогрес читання, продовження навчання та окремі чернетки практичних задач у локальному сховищі. Ctrl+Enter перевіряє задачу. Перевірка шукає потрібні конструкції, але не виконує код.
- Копіювання коду з обробкою помилок, доступні підписи полів, повідомлення про результати й посилання для переходу до основного контенту.
- Вихідні CSS-блоки перевіряються на незмінність під час збірки. Додані елементи використовують наявні кольори, шрифти, рамки й відступи.

## Мови світу

Перемикач містить **249 мов** зі списку Google Translate, отриманого 25 листопада 2026 року. П’ять вбудованих версій працюють локально та індексуються на власному домені. Решта мов відкривають поточну опубліковану сторінку в Google Translate; потрібен інтернет. Це не 249 власних SEO-версій і не переклад абсолютно всіх мов світу. Доступність зовнішнього перекладача залежить від Google та регіону користувача.

Автоматичні переклади можуть містити мовні й термінологічні неточності. Код позначено `translate="no"`, щоб не змінювати синтаксис прикладів. Підказки й завдання перекладено окремо; виконуваний код залишається без змін.

`translation-overrides.json` містить додані переклади та виправлення термінів. `i18n-auto-data.json` і старий `i18n.js` використовуються лише під час збірки, а не завантажуються відвідувачем. Для повторного заповнення виявлених пропусків можна явно запустити `node tools/complete-translations.mjs`: ця команда звертається до зовнішнього перекладача й кешує результат. Звичайна збірка працює без мережі.

## Публікація на Netlify

`netlify.toml` задає команду `npm run build` і папку публікації `dist`. Для ручного завантаження потрібно передати **вміст `dist`**, а не корінь із початковими HTML-файлами.

Основний домен береться з наявного проєкту: `https://code-lessons.netlify.app`. Якщо домен зміниться, перед збіркою задайте змінну середовища `SITE_URL` з HTTPS-адресою без завершального шляху. Збірка оновить canonical, hreflang, sitemap і адреси для перекладача.

Після публікації перевірте `/robots.txt`, `/sitemap.xml`, `/en/python.html` і старе посилання `/python.html?lang=en`. Додайте карту сайту в наявну Google Search Console. Файл підтвердження Google збережено. Локальні перевірки не підтверджують індексацію чи позиції опублікованого сайту.

## Перевірки

`npm test` перевіряє SEO всіх 100 сторінок, локальні посилання й ресурси, початкові стилі, незмінність коду між мовами, пошук, чернетки, прогрес, пошкоджене або заблоковане сховище. Звіти збірки зберігаються в `.qa/`.

Рішення щодо мовних адрес відповідають [рекомендаціям Google для багатомовних сайтів](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites). Інші мови використовують [переклад вебсторінок Google](https://support.google.com/translate/answer/2534559).
